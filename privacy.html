Privacy Policy

Effective May 7, 2026

1. No Personal Data Collected

Nagizen does not collect, store, or process personal data from any end users. This service has no user-facing interface and does not accept registrations, logins, or any form of user input.

2. Single-Operator Tool

Nagizen operates exclusively on behalf of a single operator. No data is collected from TikTok viewers or any third parties who encounter content posted by Nagi.

3. TikTok API

Nagizen uses the TikTok Content Posting API solely to upload and publish video content to an operator-owned TikTok account. No user data is accessed, read, or stored via this integration.

4. Third-Party Services

Nagizen uses the Unsplash API to source background images for videos. No personal data is transmitted to Unsplash. Content is generated programmatically without user involvement.

5. Data Retention

No personal data is retained because none is collected. Generated video content is stored locally on the operator's server only.

6. No Data Sharing or Sale

No personal data is sold, shared, rented, or disclosed to any third party.

7. Contact

Questions regarding this privacy policy may be directed to IagoAgrabah+nagi@gmail.com.
